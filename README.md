# jail.nix mirror

Read-only mirror of [jail.nix](https://sr.ht/~alexdavid/jail.nix/) by
~alexdavid (GPL-3.0), kept so Nix flakes can fetch it from GitHub instead of
hitting sourcehut on every evaluation. Branches and tags are overwritten from
upstream four times a day by `.github/workflows/mirror.yml`; nothing here is
edited by hand. Report issues upstream, not here.
